# Static, no-build port of the Morim Foundation redesign (PR #3)

## Context

PR #3 (`review/morim-redesign-wip`, branch fetched locally as `pr-3`) delivers the new
design as a React 19 / Vinext / Cloudflare Workers app under `website/`. The page
itself is plain markup, ~2,900 lines of hand-written CSS and ~1,600 lines of
framework-free logic; the React layer is thin except for the hero component. The build
target is a Cloudflare Worker, not static files, and the PR has no i18n while the live
site serves EN/RU/HE.

Goal: reproduce the PR's final experience 100% (styles, animations, interactions,
reduced-motion and keyboard behaviour) as static HTML + CSS + plain ES-module JS with
no JS build, add EN/RU/HE at separate URLs, target evergreen browsers, and optimise for
readability and long-term maintenance. The current live site stays untouched as a
reference. Exploratory material in the PR is dropped.

## Decisions (from the interview)

| Topic | Decision |
|---|---|
| Pages | Generated by a Python + Jinja2 script (`uv run --with jinja2 build.py`) from one template + per-language JSON. Outputs are committed. |
| Template granularity | Markup lives in the template; strings in JSON; repeated blocks (FAQ, program rows, team, benefit cards, nav) are arrays in JSON and looped in the template. |
| URLs | `/` = EN, `/ru/`, `/he/`; `hreflang` links on each page; old `?lang=xx` on `/` redirects client-side to `/ru/` or `/he/`; switcher stores choice in `localStorage` but never auto-redirects. |
| Translations | EN complete from the PR (with gaps fixed from the live site); RU/HE first-pass drafts written now, reusing reviewed strings from `static/js/i18n.js` where meaning matches; native review later. |
| RTL | CSS ported to logical properties (`inset-inline-*`, `margin-inline-*`, `padding-inline-*`, `text-align: start`); only artwork/tilt exceptions use `[dir="rtl"]`. |
| Display-heading glyphs | Each language's heading string carries its own inline HTML so glyph placement is a per-language editorial choice. |
| Hero | `original` variant, `static` mode only. Keep drag, poof-and-replace, notification count-up, video autoplay, session memory, reduced-motion and keyboard handling. Drop the mode switch, scroll/stay modes, the `context` variant, `/hero-options`, `/approach-v2`. |
| Widgets | Native `<dialog>` (contact/apply/socials, mobile menu), native `<details>` with WAAPI height animation (FAQ, Tbilisi results), custom `role="listbox"` for the location filter styled like the PR. Behaviour and visuals must match; no corner-cutting. |
| Videos | Same catalogue, pools, autoplay and session memory as the PR. |
| JS | Plain ES modules under `src/js/`, JSDoc where useful, no tsc assumed. |
| Tests | Port the 16 `node:test` files to zero-dependency tests; postcss-based layout test rewritten without postcss. |
| Repo layout | New site source in `src/`, generated output in `site/` (`site/index.html`, `site/ru/`, `site/he/`). Root `index.html` + `static/` (live site) untouched. |
| Links | Apply / "tell us about yourself" → `https://survey.morim.foundation/s/join-v1?src=landing&lang=<xx>`; "Get in touch" → `mailto:contact@morim.foundation`; team names → LinkedIn as on the live site; footer socials keep the placeholder dialog. |
| Switcher | A dropdown at the end of the header nav (right after FAQ; the nav sits in the centre column of the header), inline inside the mobile menu, and in the footer "Foundation" column. |
| Fonts | Copy GT Alpina Regular/Light/Medium + ABC Stefan Trial OTFs as-is; drop unused MeanHand; preload the above-the-fold faces. |
| Copy | PR copy, with the three school-leader cards taking the coordinator copy from the live site, Tel-Aviv date normalised, team placeholders kept. |
| Verification | Run the PR locally with `pkgx node@22.13` / `pkgx npm` in the scratchpad (never in the repo or user env) and compare side by side in a headless browser at 1440px and 390px. |
| Delivery | Branch `static-redesign`, logical commits, PR against `main`. No AI attribution anywhere. |

## Target layout

```
build.py                    # uv script: renders src/ → site/ (Jinja2 only dependency, inline metadata)
package.json                # 5 lines: "type": "module" + "test": "node --test tests/"; no deps, no lockfile
src/
  template.html.j2          # the page, readable as HTML; {{ t.* }} for strings, {% for %} over lists
  i18n/en.json  ru.json  he.json
  css/                      # ported stylesheets (see CSS section)
  js/                       # ES modules (see JS section)
  assets/                   # images + fonts copied from website/public
site/                       # generated, committed
  index.html  ru/index.html  he/index.html
  css/ js/ assets/          # copied verbatim by build.py (real files; GitHub Pages does not follow symlinks)
tests/*.test.mjs            # node --test, imports src/js/*.js
docs/plans/static-redesign.md
```

`site/` is served at `morim.foundation/site/` once merged; promotion to root later is a
move of `site/*` to `/` (plus CNAME). All asset URLs in the template are relative to the
page (`{{ root }}css/…` where `root` is `""` for EN and `"../"` for RU/HE), so the same
output works at `/site/`, at `/`, and from a local static server.

## build.py

Single file, `# /// script` header with `dependencies = ["jinja2"]`, `requires-python >= 3.12`.

- `LANGS = {"en": {"dir": "ltr", "path": ""}, "ru": {"dir": "ltr", "path": "ru/"}, "he": {"dir": "rtl", "path": "he/"}}`
- For each language: load `src/i18n/<lang>.json`, render `template.html.j2` with
  `{t, lang, dir, root, langs}` (`langs` gives the switcher its hrefs and `hreflang`
  alternates), write to `site/<path>index.html`.
- Copy `src/css`, `src/js`, `src/assets` to `site/` (`shutil.copytree(dirs_exist_ok=True)`),
  removing stale files first.
- `--serve [port]` flag: build, then serve `site/` with `http.server` (ES modules do not
  load over `file://`). `--check` flag: fail if `site/` differs from a fresh render (for a
  future CI step; not required now).
- Jinja2 configured with `autoescape=False` for `t.*` values that are intentionally HTML
  (headings with glyphs, paragraphs with `<br>`/`<span>`); everything in the JSON is
  trusted authored content. `trim_blocks`/`lstrip_blocks` on for readable output.
- Fails loudly on a missing key (`StrictUndefined`) so an untranslated string cannot ship
  silently.

### Hero DOM contract

Template renders the shell: `<section class="hero hero-editorial" data-playing="false" data-looping="false" data-media-layout="static" data-label-icon data-label-media data-label-media-dismiss data-video-unavailable data-help-desktop data-help-compact>` with `.hero-mobile-content > h1` always present (its styles only apply ≤700px, so no JS swap), an empty `.hero-accents[role=group]`, and `#hero-app-help`. React renders nothing inside `.hero-accents` before its first effect, so there is no no-JS content to preserve there.

Click → poof → replace sequence, keyboard (`click.detail === 0`) and compact-touch (no drag, tap dismisses) paths, and the fifteen porting pitfalls (stale closures, iframe reload, `lostpointercapture` ordering, measure-before-mutate, `box-sizing` and `height: 0`, `file://` and Twitch `new URL(origin)`) are documented in the design notes and will be carried into code comments where non-obvious.

## Widgets: native replacements with the PR's exact motion

All five shadcn wrappers use Base UI; the site CSS already overrides their animation with explicit transitions, so the numbers below are the PR's, not Tailwind defaults.

| Widget | Native element | Motion to reproduce |
|---|---|---|
| FAQ accordion | `<details class="faq-item"><summary class="faq-trigger">` | Content height 0→auto over 250ms `cubic-bezier(0.22,1,0.36,1)`, opacity 200ms ease; chevron `›` rotates 90°→−90° over 250ms same easing. Items are independent (PR accordion is not single-open). |
| Tbilisi results | `<button class="button results-button" aria-expanded aria-controls>` + `<div class="program-results-content" role="region" hidden>` (a `<summary>` must be a direct child of `<details>`, but this trigger sits inside the program row grid) | Height 360ms same curve, opacity 240ms ease; label toggles between `data-label-open`/`data-label-closed`; reset to closed when the row is filtered out (React remounted it). |
| Contact / apply / social dialogs | `<dialog class="morim-dialog">` + `::backdrop` | Backdrop `rgb(0 0 0 / .1)` + `backdrop-filter: blur(4px)`, fade 100ms ease-out in / ease-in out; panel fade + scale .95→1 over 100ms; centred; ghost close button top-right with sr-only label; Escape, backdrop click, focus return. |
| Mobile menu | `<dialog class="mobile-menu-panel">` | Backdrop opacity 150ms; panel slides in 2.5rem from the inline-end edge + fades, 200ms ease-in-out; width `min(100%, 28rem)`; closes when a link is clicked or the viewport crosses 701px. |
| Location filter | `<button class="location-select" aria-haspopup="listbox">` + `<ul role="listbox" class="location-options">` | PR popup has `animate-none` in practice (item aligned with trigger), so no open animation; item hover/focus background `#f4f3f0`; check mark on the selected item; keyboard: ArrowUp/Down, Home/End, Enter/Space, Escape, type-ahead first letter; closes on outside click; changing the value runs the FLIP row animation (240ms ease-out) from `useProgramMotion`. |

Height animation technique for `<details>`: on `summary` click, `preventDefault`; opening sets `open` and `data-state="open"`, measures `scrollHeight`, runs `content.animate([{height:'0px', opacity:0},{height:H, opacity:1}])`; closing sets `data-state="closed"`, animates to 0, and removes `open` in `onfinish` (not `.finished`, so a cancelled animation never resolves the close path). Chevron rotation keys on `data-state`, not `[open]`. `overflow:hidden` on the wrapper, padding on an inner body so `height:0` really is zero under `border-box`. A `toggle` listener resyncs `data-state` when the browser opens a `<details>` itself (find-in-page). No reliance on `interpolate-size` or `::details-content`.

Dialog motion: enter via `@starting-style` on `dialog[open]` and `::backdrop`; exit via a `data-closing` attribute that `closeDialog` awaits before calling `close()`. Works in all evergreen browsers without `transition-behavior: allow-discrete` on `overlay`.
